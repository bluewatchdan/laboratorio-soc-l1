# 🛡️ Laboratório SOC Nível 1

## 📌 Sobre o projeto

Este repositório reúne meus estudos,
laboratórios práticos e projetos de
cibersegurança defensiva, com foco no
desenvolvimento de habilidades necessárias
para atuar como Analista de Segurança em um
Centro de Operações de Segurança (SOC)
Nível 1.

## 🎯 Objetivos

- Desenvolver habilidades práticas de
  monitoramento de segurança.
- Aprender a analisar logs e identificar
  atividades suspeitas.
- Praticar a triagem e investigação de
  alertas de segurança.
- Compreender os fundamentos de resposta
  a incidentes.
- Documentar investigações e evidências
  técnicas.

## 🔎 Áreas de estudo

- Redes de computadores e protocolos TCP/IP.
- Segurança de sistemas Windows e Linux.
- Análise de logs e eventos de segurança.
- SIEM e correlação de eventos.
- Fundamentos de EDR.
- Investigação de ameaças e resposta
  a incidentes.

## 🧪 Projetos práticos

Os projetos serão adicionados conforme o
desenvolvimento dos laboratórios.

## 📚 Sobre este portfólio

Este repositório documenta minha evolução
prática em cibersegurança, com foco em
conhecimentos aplicáveis ao cotidiano
de um SOC Nível 1.
